Sushi Incremental UI Pack

Chunky, bouncy menus for a blocky sushi shop: rice-paper panels with a nori band, tuna-red title tabs, and FredokaOne text with a thick ink outline that stays readable over bright grass.

Style guide

Every colour is a Roblox Color3.fromRGB value. Outlines use the nori-ink colour, never pure black. Drop shadows are hard and point straight down: ink at 35%, offset 4–8 px, no blur.

PNG export

Rebuild with node ui-pack/build.mjs. Upload the files from ui-pack/png/ with Studio's Asset Manager (Bulk Import). For each frame, set ImageLabel ScaleType = Slice, the SliceCenter below, and leave the label's background transparent. The bottom shadow is part of the image, so keep the padding as is. Pills and circles only stretch sideways. bar_fill_white is white so you can tint it with ImageColor3.
